使用说明

WebSocket 端点

ws://localhost:8080/ws/interview?userId={userId}

消息格式 (JSON)

{
  "id": "uuid",
  "type": "TEXT|CHAT|HEARTBEAT|PONG|ACK|ERROR|VOICE_START|VOICE_CHUNK|VOICE_END",
  "sender": "发送者ID",
  "receiver": "接收者ID",
  "content": "消息内容",
  "timestamp": 1234567890,
  "sessionId": "会话ID",
  "chunkIndex": 0,
  "totalChunks": 1,
  "metadata": {}
}

REST API

  • POST /api/ws/send/{sessionId} - 发送消息到指定会话
  • POST /api/ws/send/user/{userId} - 发送消息到指定用户的所有会话
  • POST /api/ws/broadcast - 广播消息到所有会话
  • GET /api/ws/session/{sessionId} - 查询会话状态
  • GET /api/ws/user/{userId}/sessions - 查询用户的所有会话
  • GET /api/ws/sessions - 查询所有在线会话
  • GET /api/ws/online-count - 查询在线会话数量
